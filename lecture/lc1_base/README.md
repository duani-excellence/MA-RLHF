# base

语言模型的核心在于理解文本语义，对于语言的机器表示主要有两个步骤：

- 离散化：将文本离散成 token 序列
- 连续化：离散的数据表示成连续表示

| 文件名                  | 介绍                                                         | 必读 |
| ----------------------- | ------------------------------------------------------------ | ---- |
| `embedding.ipynb`       | 从词表征角度介绍机器如何来表示文本语义，实现 word2vec, 文本语义表示, 词在上下文 | ✅    |
| `tokenizer_basic.ipynb` | 从零手撕一个字符级分词器                                     | ✅    |
